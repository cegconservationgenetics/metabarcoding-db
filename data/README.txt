Put the curated database files in this folder.

Each file must be named:      <PrimerName>_tax.tsv
and contain two tab-separated columns:

Feature_ID	Taxonomy

Expected files for this project:

  12SV5_tax.tsv
  COI175_tax.tsv
  fwh2_tax.tsv
  mlCOIint_tax.tsv
  Vert16S_tax.tsv

To add a primer that is not in the list above, add its file name to
DEFAULT_FILES near the top of app.js (see the main README).
